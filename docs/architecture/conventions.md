# Conventions

| Item | Convention | Example |
|---|---|---|
| Block id | `<family>.<name>`, lower case, singular | `business.lms` |
| Python package | `mek_<name>` | `mek_lms` |
| Database | schema `<name>`, table `<entity>` | `lms.course` |
| HTTP path | `/api/<name>/v<major>/...` | `/api/lms/v1/courses` |
| Permission | `<name>.<entity>.<action>` | `lms.course.edit` |
| Event | `<entity>.<past-tense verb>@<major>`; CloudEvents type `et.mek.<entity>.<verb>.v<major>` | `enrollment.activated@1` |
| Port, query | PascalCase with major version | `PaymentProviderV1`, `PartyQueryV1` |
| Setting | snake_case under the block name | `lms.lessons_locked_by_default` |
| Client extension | `client.<client>.<name>` | `client.kasina.cohorts` |

The registry checks these in the manifest validators, so a wrong name fails the build.

## Versioning
Semantic versions for blocks, events, ports, queries and HTTP APIs. A breaking change means a new major version and a
deprecation period. Within a major version changes are additive: add fields, never rename or remove; consumers ignore
unknown fields. Migrations are forward-only and use expand/contract.

Block stages: **proposed** (planned) → **incubating** (built for the first product, may change freely) → **beta** (a second
product uses it; contracts versioned) → **stable** (contracts frozen at a major) → **deprecated** → **retired**. Blocks at
version 0.x are not yet stable; product manifests refer to them as `@0`.

## HTTP API
Resource-oriented JSON, plural nouns, actions as sub-resources (`POST /enrollments/{id}/revoke`). Errors are RFC 9457
problem details with a stable type and a correlation id. Cursor pagination (limit up to 200). `Idempotency-Key` on money
operations. Dates are ISO 8601 UTC; money is a decimal string plus an ISO 4217 code. `Accept-Language` selects the language
of messages and generated documents. OpenAPI is generated by FastAPI; breaking changes fail CI.

## Code
- Domain rules are plain Python with no FastAPI or SQLAlchemy imports, so they are testable in milliseconds.
- Models extending `mek_kernel.types.StrictModel` reject unknown fields.
- English is the language of code, data and interfaces. Every visible string is wrapped for translation.
- Ruff (line length 120), mypy strict on source, one pull request per slice.
